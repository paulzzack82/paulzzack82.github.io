데이터 처리 안내

개인정보처리방침

시행일: 2026년 11월 13일

이 방침은 개인용 앱 낭독 영상 제작이 Google 계정 및 YouTube 데이터를 처리하는 방법을 설명합니다. 운영자가 자신의 채널에 대해 승인한 작업에 적용됩니다.

1. 접근하는 데이터

승인한 YouTube 채널의 식별자와 채널명, 영상 식별자와 제목·설명·처리 상태·공개 범위, 재생목록과 재생목록 항목 정보를 작업에 필요한 범위에서 조회합니다. 업로드할 영상 파일과 입력한 영상 정보도 처리합니다.

Google이 발급한 OAuth Access token과 Refresh token을 사용하여 승인된 작업을 인증합니다. 앱이 Google 계정 비밀번호를 받거나 저장하지 않습니다.

2. 이용 목적

  • 승인된 업로드 대상 채널 확인
  • 낭독 영상 업로드와 영상 정보·공개 범위 관리
  • 재생목록 생성·등록·조회 등 관리
  • 업로드 결과 확인, 작업 재개 및 중복 업로드 방지

Google에서 받은 사용자 데이터를 판매하거나 광고 타기팅에 사용하지 않습니다. 범용 AI 또는 머신러닝 모델의 학습을 위해 사용하지 않습니다.

3. 보관과 보호

OAuth 클라이언트 비밀값과 Refresh token은 GitHub Actions의 암호화된 Secrets에 보관합니다. 채널·영상 식별자와 작업 진행 기록은 운영자의 비공개 작업 저장소에 기록하여 후속 작업과 결과 확인에 사용합니다.

인증 토큰과 비밀값을 이 공개 안내 사이트에 게시하지 않습니다. Google API와 통신할 때 HTTPS를 사용하며 작업에 필요한 승인 범위를 사용합니다.

4. 데이터 전송과 서비스 제공자

영상 파일·영상 정보와 인증 요청은 승인된 작업을 실행하기 위해 Google 및 YouTube로 전송됩니다. 자동 작업의 실행과 비공개 작업 기록·인증 정보 보관에는 GitHub 서비스를 사용합니다.

운영자가 선택한 공개 범위에 따라 YouTube의 영상과 해당 정보가 시청자에게 공개될 수 있습니다. 안내 사이트의 접속 기록은 호스팅 제공자의 서비스 정책에 따라 처리될 수 있습니다.

5. 보관 기간과 삭제

인증 정보는 채널 연결과 승인된 자동 작업에 필요한 동안 보관합니다. 작업 식별자와 진행 기록은 결과 확인과 중복 처리 방지에 필요한 동안 보관하며 운영자가 비공개 저장소에서 삭제할 수 있습니다.

Google 계정의 제3자 앱 연결 관리에서 이 앱의 접근 권한을 철회할 수 있습니다. 연결을 종료할 때 운영자는 저장한 인증 정보를 삭제하고 자동 작업을 중단할 수 있습니다. YouTube에 이미 업로드한 영상과 재생목록의 삭제는 YouTube에서 별도로 관리합니다.

6. Google API 데이터 사용

Google API를 통해 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 따릅니다. 앱의 채널 관리 기능에 필요한 목적으로만 데이터를 사용합니다.

7. 문의와 변경

데이터 처리·연결 해제·삭제 문의는 Google OAuth 승인 화면에 표시된 사용자 지원 이메일로 보내실 수 있습니다. 데이터 처리 방식이 변경되면 이 페이지를 갱신하고 시행일을 표시합니다.
