개인용 블로그 운영 도구

AI픽24

운영자가 승인한 원고와 이미지를 본인의 Blogger 블로그에 등록하고, 게시 결과를 확인하는 개인용 자동화 앱입니다.

운영 블로그: AI픽24

앱이 하는 일

  • 연결한 계정이 관리하는 블로그 목록에서 게시 대상 블로그를 확인합니다.
  • 준비된 글과 이미지를 등록하고 제목·본문·라벨·공개 상태를 관리합니다.
  • 기존 게시물과 작업 기록을 대조해 중복 게시를 방지하고 등록 결과를 확인합니다.

공개 여부는 운영자가 정한 작업 설정에 따릅니다. 이 앱은 개인 운영용이며, 불특정 다수의 계정을 연결받는 서비스로 운영하지 않습니다.

Google 계정 연결

운영자가 Google의 공식 동의 화면에서 허용한 Blogger 권한으로 블로그를 조회하고 글·이미지를 등록·관리합니다. 계정 비밀번호를 이 안내 사이트에 입력하는 방식으로 연결하지 않습니다.

앱의 자동 작업은 운영용 GitHub Actions에서 실행됩니다. 안내 페이지에는 계정 연결 양식이나 토큰 입력란을 두지 않습니다.

데이터 처리와 이용 안내

접근하는 정보와 보관·삭제 방법은 개인정보처리방침에서, 앱의 이용 범위는 이용약관에서 확인하실 수 있습니다.

앱 운영과 데이터에 관한 문의는 Google OAuth 동의 화면에 표시된 사용자 지원 이메일로 보내실 수 있습니다.
