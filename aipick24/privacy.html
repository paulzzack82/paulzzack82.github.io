개인정보처리방침

시행일: 2026년 11월 13일

이 방침은 개인용 블로그 운영 앱 AI픽24가 Google 및 Blogger 데이터를 처리하는 방법을 설명합니다. 운영자가 관리 권한을 갖고 사용을 승인한 블로그의 작업에 적용됩니다.

1. 접근하고 처리하는 정보

연결한 계정이 관리하는 블로그의 식별자·이름·주소, 게시물의 식별자·제목·본문·라벨·초안 및 공개 상태를 작업에 필요한 범위에서 조회합니다. 운영자가 준비한 원고·HTML·이미지 파일과 게시 결과도 처리합니다.

승인된 Blogger 작업의 인증에는 Google OAuth 액세스 토큰과 갱신 토큰을 사용합니다. 앱이 Google 계정 비밀번호를 받거나 저장하지 않습니다.

2. 정보의 이용 목적

  • 승인된 게시 대상 블로그 확인
  • 원고·이미지 등록과 제목·본문·라벨·공개 상태 관리
  • 게시 결과 확인, 중단된 작업 재개와 중복 게시 방지

Google API에서 받은 사용자 데이터를 판매하거나 광고 타기팅에 사용하지 않습니다. 해당 데이터를 범용 AI 또는 머신러닝 모델의 학습을 위해 사용하지 않습니다.

3. 보관과 보호

OAuth 클라이언트 비밀값과 갱신 토큰은 GitHub Actions의 암호화된 Secrets에서 관리합니다. 원고·이미지·게시물 식별자·작업 진행 기록은 운영자의 비공개 작업 저장소에서 관리하며 자동 작업과 결과 확인에 사용합니다.

인증정보를 이 공개 안내 사이트에 게시하지 않습니다. Google API와의 통신에는 HTTPS를 사용합니다.

4. 전송과 공개 범위

인증 요청과 원고·게시물 정보·이미지는 승인된 블로그 작업을 수행하기 위해 Google 및 Blogger로 전송됩니다. 자동 작업 실행과 작업 자료·인증정보 보관에는 GitHub 서비스를 사용합니다.

운영자가 공개 발행을 설정한 글과 이미지는 블로그 방문자에게 공개됩니다. 이 안내 사이트는 별도 로그인·입력 양식·방문 분석 도구를 두지 않습니다. 안내 사이트의 접속 기록은 호스팅 제공자 GitHub의 서비스 정책에 따라 처리될 수 있습니다.

5. 보관 기간과 삭제

인증정보는 승인된 블로그 연결과 자동 작업에 필요한 동안 보관합니다. 작업 자료와 진행 기록은 결과 확인과 중복 처리 방지에 필요한 동안 보관하며 운영자가 비공개 저장소에서 삭제할 수 있습니다.

Google 계정의 연결된 앱 관리에서 이 앱의 접근 권한을 철회할 수 있습니다. 연결을 종료할 때 운영자는 자동 작업을 중단하고 GitHub Actions Secrets에 보관된 인증정보를 삭제할 수 있습니다. 이미 Blogger에 등록된 글과 이미지는 별도로 관리·삭제해야 하며, 권한 철회만으로 자동 삭제되지는 않습니다.

6. Google API 데이터 사용

Google API를 통해 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 따릅니다. 해당 정보는 앱의 블로그 관리 기능에 필요한 목적으로 사용합니다.

7. 문의와 변경

데이터 처리·연결 해제·삭제에 관한 문의는 Google OAuth 동의 화면에 표시된 사용자 지원 이메일로 보내실 수 있습니다. 데이터 처리 방식이 변경되면 이 페이지를 갱신하고 시행일을 표시합니다.
